# 잠실도 몬스터·정령 도트 에셋

`잠실도_기획서_v3.pdf`의 명시된 몬스터 19종과 기본 정령 6종, 총 25종의 개별 PNG 이미지다.

## 폴더와 파일명 규칙

- `monsters/chapter_01` ~ `chapter_04`: 장별 몬스터
- `spirits/`: 정령 6종
- `enemy_chNN_normal_*.png`: 장별 일반 적
- `boss_chNN_stage03_*.png`: 장 3스테이지 중상위 보스
- `boss_chNN_stage05_*.png`: 장 5스테이지 최종 보스
- `spirit_<element>_<name>.png`: 정령. 이름 미정인 혼돈 정령은 `hidden_unnamed`로 표기
- `assets_manifest.json`: 모든 파일의 기획서 한글명·영문명·역할·경로를 연결하는 정형 목록

## 개발 시 주의

- PNG들은 투명도를 포함한 **정적인 도트풍 콘셉트 스프라이트**다.
- 각 파일의 원본 캔버스 크기와 피사체 비율이 다르므로 게임 내 사용 전 공통 기준 크기, 피벗, 충돌 상자, 렌더링 스케일을 정해야 한다.
- 이동·공격·피격 애니메이션 프레임은 아직 없다.
- 기획서에서 정령 중급/상급과 일부 미들 보스의 세부 설정은 미정이다. 따라서 이 파일 묶음에는 임의로 확정한 진화체나 미정 보스가 없다.

## AI 코딩 도구에 전달할 예시

> `assets_manifest.json`을 읽고 `type`, `chapter`, `rank`, `element`에 따라 몬스터·정령 에셋을 로드해 줘. 이미지 원본 크기를 곧바로 충돌 판정에 사용하지 말고, 별도 게임플레이 크기와 충돌 상자를 정의해 줘.
