# 잠실도 에셋 확장팩 v1

기존 기획서 기반 25종 도트 캐릭터에 추가한 **정령 진화 시트 6장(중급·상급 12종)**, **몬스터 스킬 이펙트 시트 4장(총 19효과)**, **정령 스킬 이펙트 시트 6장(총 24효과)** 을 설명한다.

## 신규 폴더

- `evolution_sheets/`: 속성당 한 장. 왼쪽은 중급, 오른쪽은 상급.
- `effects/monsters/`: 장별 스킬 이펙트 아틀라스. 1~3장은 2열×3행에 마지막 칸 비움, 4장은 2열×2행.
- `effects/spirits/`: 정령당 2열×2행 아틀라스. 순서는 **좌상: 단검, 우상: 장검, 좌하: 활, 우하: 너클**.
- `extension_manifest.json`: 스프라이트 시트 내 각 칸의 `row`, `column`, `skill_name_ko`, 주체 ID와 대응 파일 경로를 담은 목록.

## 기획서에서 확정되지 않은 부분

- **정령 진화체 이름·분기:** 이미지 아이디어만 제작한 것. 아직 공식 명칭 없음.
- **몬스터별 공격기:** 원문에는 개별 공격 스킬이 없으므로 이번 이펙트와 이름은 새로 제안한 시안.
- **혼돈 정령:** 매번 무작위 효과가 발동한다는 원문을 반영해 4가지 시각 샘플만 제작. 특정 무기에 묶지 않음.

## 개발 시 주의

아틀라스는 정적인 PNG 콘셉트 이미지이며, 시간에 따라 변하는 공격/회복 애니메이션 프레임은 아니다. 이미지별 크기와 투명 여백이 다르므로 **행·열 분할 후 트리밍, 게임 내 크기·기준점·투사체 방향·프레임 시간·충돌 판정**을 통일하는 작업이 필요하다. 개발 도구에 `extension_manifest.json`을 먼저 제공하면 각 칸의 매핑을 추측하지 않고 처리할 수 있다.
